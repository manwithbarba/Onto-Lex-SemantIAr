# SemantIAr · Repertorio léxico rioplatense

Repertorio interactivo de términos y siglas para docencia e investigación. Incluye variantes de escritura, sentidos, pistas de contexto y vínculos a SNOMED CT cuando corresponde.

[Abrir el repertorio en GitHub Pages](https://manwithbarba.github.io/Onto-Lex-SemantIAr/)

[Descargar el repertorio en CSV](https://manwithbarba.github.io/Onto-Lex-SemantIAr/repertorio-lexico-rioplatense.csv). El archivo contiene una fila por entrada y usa UTF-8. Las columnas con listas o condiciones contienen JSON.

Para consultarlo sin conexión, descargá `index.html` y abrilo en un navegador. El archivo incluye los datos del repertorio y su interfaz. El repositorio distribuye entradas léxicas y frecuencias agregadas.
